# Galaxy Math

Juego arcade matematico en HTML, CSS y JavaScript con soporte para escritorio, tablet y celular.

## Ejecutar localmente

Abre `index.html` en tu navegador.

## Estructura

- `index.html`: punto de entrada principal
- `style.css`: estilos y responsive
- `script.js`: logica del juego
- `assets/`: imagenes, audio y recursos visuales
